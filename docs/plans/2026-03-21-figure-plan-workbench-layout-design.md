# Figure Plan Workbench Layout Design

**背景**

当前图表规划工作台采用三栏布局：
- 左栏按 `figure_framework` 提供筛选导航
- 中栏展示图表规划卡片
- 右栏展示选中图表的详情与编辑能力

左栏与中栏都在重复传达 “fig 编号 + 标题 + 数量/状态” 这类信息，导致工作台横向空间被重复信息占用，核心操作入口分散。

**目标**

将左栏导航与中栏图表卡片合并成一个主列表区，保留筛选能力，同时把编辑能力切换为更清晰的二级编辑层，降低重复信息和认知负担。

**设计决策**

1. 工作台改为两栏布局
- 左栏作为主工作列表，负责展示图表规划卡片并承载筛选入口
- 右栏继续显示当前选中图表的详情、素材上传和 AI 讨论

2. 左栏只保留轻筛选
- 第一版保留 `全部` 和 `未关联`
- 去掉按 `figure_framework` 展开的独立导航列表

3. 编辑能力迁移到二级编辑层
- 卡片区和详情区的“编辑”操作统一打开页内覆盖层
- 覆盖层承载原有 `figureNo / title / claimText / sectionKey / briefText` 表单
- 右栏详情区改成以只读展示为主

4. 保留现有详情动作
- 详情区仍保留确认规划、删除、素材上传、AI 讨论
- 编辑入口保留，但不再原地切换成表单

**状态设计**

- 保留 `selectedPlanId` 作为右侧详情的选中态
- 保留 `selectedFilterKey` 管理 `全部 / 未关联`
- 新增 `editingPlanId` 控制当前二级编辑层打开状态

**测试策略**

- 验证合并后的列表仍支持 `全部 / 未关联` 筛选与右侧详情切换
- 验证点击“编辑”会打开二级编辑层，并正确调用现有 patch mutation
- 验证删除后仍会切换到下一个可见图表
